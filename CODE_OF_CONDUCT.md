# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Criticise code, not people.

## What that means here

**Good:** "This breaks on Firefox because `SpeechRecognition` isn't available —
here's a repro." · "I'd push back on this approach, because…" · "I don't
understand why this needs a ref; can you explain?"

**Not good:** personal attacks, harassment, sexual attention or advances,
sustained disruption, publishing someone's private information, dismissing
people for what they don't know yet.

This project renders an anime character, which attracts a certain amount of
unpleasantness. Sexualised commentary about the rigs, the personas, or anyone in
the issue tracker is not welcome. The characters are animation targets; the
people here are people.

## Scope

Applies in issues, pull requests, discussions and commit messages — anywhere
someone is representing this project.

## Enforcement

Report to <daisukenagata0209@gmail.com>. Reports stay private. Responses range
from a private word through edited or deleted comments to a permanent ban,
depending on severity and whether it keeps happening.

The maintainer makes the call and is held to the same standard. If the problem is
the maintainer's behaviour, say so publicly in an issue — there is no one else to
escalate to, and that is the honest answer rather than a fictional committee.
